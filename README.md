# Domain-Adaptive Fine-Tuning of SLM

This repository contains notebook-based experiments for domain-adaptive fine-tuning and evaluation of Small Language Models (SLMs) across multiple domains.

## Repository Structure

- `Medical Domain/`
  - `MedicalFineTuning.ipynb`
  - `trulens_eval.ipynb`
- `finance/`
  - `finance-finetuning.ipynb`
  - `trulens_eval.ipynb`
- `securityy domain/`
  - `notebook_fixed.ipynb`
  - `Dataset Details.xlsx`

## Notes

- Work is organized primarily in Jupyter notebooks.
- Each domain folder contains fine-tuning and/or evaluation artifacts.
